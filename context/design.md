# Design Context

## Dirección Visual
- Dark UI limpia, editorial y técnica.
- Contraste alto, brillo contenido y acento frío sutil.
- Sensación general: precisión, calma y madurez.

## Reglas de UI
- Usar superficies con borde tenue, fondo translúcido y blur moderado.
- Mantener tipografía display para titulares y sans para lectura continua.
- Usar chips, cards y shells de sección como patrones base repetibles.
- Favorecer grids amplios, mucho aire y ritmo vertical consistente.

## Jerarquía
- Cada sección debe abrir con eyebrow, título y descripción corta.
- Los títulos deben comunicar valor, no solo nombrar bloques.
- El contenido debe escanearse rápido en desktop y mobile.

## Estilo de Interacción
- Hover y focus sutiles; nada ruidoso o juguetón.
- Motion mínima y con propósito.
- Navegación simple por anchors antes de introducir complejidad adicional.

## Restricciones
- No usar gradients agresivos ni colores saturados.
- No llenar la UI con logos, badges o métricas sin contexto.
- No romper la consistencia del sistema base definido en `src/style.css`.
